# [팀 이름] 팀 홈페이지 제작 계획서

## 1. 만들 것
- 한 장짜리 팀 소개 페이지 `index.html` (PRD: prd.md)

## 2. 파일 구조
```
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          ← 만들 파일
└─ images/
   ├─ logo.png         ← 로고 (없으면 임시 글자 로고)
   └─ reference.png    ← 참고 이미지 (선택)
```

## 3. 준비물 체크
| 준비물 | 상태 | 없을 때 |
|---|---|---|
| 로고 `images/logo.png` | 있음 / 없음 | 팀 이름 첫 글자로 임시 로고 → 나중에 파일만 넣으면 교체 |
| 참고 이미지 `images/reference.png` | 있음 / 없음 | PRD의 디자인 가이드만 따름 |
| 문의 채널 · 이메일 | 실제 / 예시 | 예시 값으로 넣고 나중에 바꿈 |

## 4. 만드는 순서
| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 뼈대: 헤더 · 섹션 4개 · 푸터 | 메뉴 클릭 시 섹션으로 이동 |
| 2 | 디자인 변수(색 · 글꼴 · 모서리) 적용 | PRD 색과 같은지 |
| 3 | ① 한 줄 소개 | 제목이 한눈에 읽히는지 |
| 4 | ② 업무 카드 N장 | 카드 내용이 PRD와 같은지 |
| 5 | ③ 준비 중 카드 | 점선 + "준비 중" 배지 |
| 6 | ④ 문의 | 채널 · 응답 시간 표시 |
| 7 | 휴대폰 대응 | 375px에서 가로 스크롤 없음, 햄버거 메뉴 |
| 8 | 최종 점검 | PRD 완료 기준 체크 |

## 5. 섹션별 구현 메모
| 섹션 | 레이아웃 | 데스크톱 → 휴대폰 |
|---|---|---|
| 헤더 | 로고 왼쪽, 메뉴 오른쪽, 위에 고정 | 메뉴 → 햄버거 |
| 한 줄 소개 | 글 왼쪽 + 로고 오른쪽 | 위아래로 쌓기 |
| 업무 카드 | N열 그리드 | 2열 → 1열 |
| 도구 | 3열 그리드 | 1열 |
| 문의 | 진한 메인 색 배경, 3칸 | 1열 |

## 6. 확인 방법
- 브라우저로 `index.html`을 열어 본다 (더블클릭)
- 창을 좁혀 휴대폰 폭에서 본다
- PRD 12번 완료 기준을 하나씩 체크한다

## 7. 만든 뒤 고치기 예시
- "업무 카드를 하나 더 넣어 줘"
- "색을 ___ 계열로 바꿔 줘"
- "멤버 소개 칸을 문의 위에 추가해 줘"
