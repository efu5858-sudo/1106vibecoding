# [팀 이름] 로고 만들기 — ChatGPT용 프롬프트

## 1. 기본 프롬프트 (그대로 복사해서 붙여 넣기)

```
[팀 이름] 팀의 로고를 만들어 줘.
[메인 색] 계열, 단순한 아이콘 + 팀 이름,
흰 배경, 정사각형.
아이콘은 [아이콘 아이디어 1]을 단순한 도형으로 표현해 줘.
글자는 [팀 이름 표기, 예: 영문 대문자 + 한글 작게] 로 넣어 줘.
```

## 3. 다시 뽑을 때 쓰는 문장
- "더 단순하게, 선 굵기를 줄여 줘"
- "아이콘만 따로, 글자 없이 한 장 더 만들어 줘" ← 홈페이지 헤더·파비콘용
- "색을 더 진한 [색]으로 바꿔 줘"
- "글자가 깨지지 않게 팀 이름 철자를 정확히 [팀 이름]으로 넣어 줘"
