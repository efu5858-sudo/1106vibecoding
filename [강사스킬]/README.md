# 수강생용 스킬 2종

대화하면서 기획서를 만들고, 확인을 받은 뒤 실제 웹페이지까지 만들어 주는 스킬입니다.

| 스킬 | 이렇게 말하면 시작 | 결과물 |
|---|---|---|
| **team-page-prd** · 팀 홈페이지 PRD 제작기 | "팀 소개 페이지 만들고 싶어" | PRD · 로고 프롬프트 · 제작 계획서 → (만들까요?) → `index.html` |
| **work-os-builder** · 나만의 업무 OS | "내 업무 OS 만들고 싶어" | OS 기획서 · 제작 계획서 → (만들까요?) → `index.html` |

두 스킬 모두 **계획서까지 만든 뒤 "만들까요?" 하고 멈춥니다.** 계획서를 읽어 보고 고칠 곳이 있으면 말하고, 괜찮으면 "만들어 줘"라고 하면 됩니다.

## 설치

**받기**: 이 폴더의 [`스킬2종.zip`](스킬2종.zip) → **Download raw file**(다운로드 버튼). 또는 저장소 첫 화면 초록색 **Code** → **Download ZIP**으로 받아서 `[강사스킬]` 폴더 안의 두 폴더를 씁니다. git을 쓴다면 `git pull`.

압축 파일을 풀면 `team-page-prd/`, `work-os-builder/` 폴더가 나옵니다. 쓰는 도구에 맞는 곳에 **폴더째** 넣으세요.

| 쓰는 도구 | 넣을 곳 | 비고 |
|---|---|---|
| **Codex** | 작업 폴더 안 `.agents/skills/` | 모든 폴더에서 쓰려면 `~/.codex/skills/` |
| **Claude Code** (데스크톱 앱 Code 탭 · 터미널) | 작업 폴더 안 `.claude/skills/` | 모든 폴더에서 쓰려면 `~/.claude/skills/` |
| **Claude 앱** (claude.ai) | 설정 → 기능(Capabilities) → 스킬 → zip 파일 업로드 | 파일 저장 대신 화면에 결과를 보여 줘요 |

넣은 뒤에는 Codex · Claude Code를 **한 번 껐다 켜야** 스킬을 알아봅니다.

다 넣으면 이렇게 보여야 합니다. `SKILL.md`가 스킬 이름 폴더 바로 안에 있어야 해요.

```
내작업폴더/
└── .agents/skills/          (Claude Code는 .claude/skills/)
    ├── team-page-prd/
    │   ├── SKILL.md
    │   ├── references/
    │   └── templates/
    └── work-os-builder/
        ├── SKILL.md
        ├── references/
        └── templates/
```

> `.agents`, `.claude`처럼 점(.)으로 시작하는 폴더는 탐색기에서 숨겨져 보일 수 있어요. 탐색기 → 보기 → 숨긴 항목 켜기.

## 쓰는 법

### 1. 팀 홈페이지 PRD 제작기

```
팀 소개 페이지 만들고 싶어
```

1. 질문 4묶음에 답합니다: 어떤 팀인지 → 누가 보는지 → 어떤 내용을 넣을지 → 분위기
2. `team-page/` 폴더에 `prd.md`, `logo-prompt.md`, `build-plan.md`가 생깁니다.
3. `logo-prompt.md`의 프롬프트를 ChatGPT에 붙여 넣어 로고를 만들고, 그 이미지를 다시 올려 줍니다. 참고하고 싶은 사이트 화면 캡처가 있으면 같이 올립니다.
4. "만들까요?"에 답하면 `index.html`이 만들어집니다.

### 2. 나만의 업무 OS

```
내 업무 OS 만들고 싶어
```

1. 첫 질문은 **"업무에서 가장 반복되고 불편한 건 무엇인가요?"** 입니다.
2. 추천 화면 모듈(오늘 할 일, 기록 표, 자주 쓰는 문구 등) 중 2~3개를 고릅니다.
3. `my-os/` 폴더에 `os-prd.md`, `os-build-plan.md`가 생깁니다.
4. "만들까요?"에 답하면 `index.html`이 만들어집니다. 더블클릭해서 열고 즐겨찾기에 넣어 두세요.
5. 입력한 내용은 **내 브라우저에만** 저장됩니다. 가끔 화면의 **백업** 버튼으로 파일을 받아 두세요.

## 막힐 때

| 증상 | 해결 |
|---|---|
| 말해도 스킬이 시작되지 않는다 | 도구를 껐다 켜기. 그래도 안 되면 "team-page-prd 스킬로 시작해 줘"처럼 이름을 직접 말하기 |
| 스킬 폴더 안에 폴더가 하나 더 생겼다 | 압축을 풀 때 한 단계 더 생긴 것. `SKILL.md`가 `team-page-prd/` 바로 안에 오게 옮기기 |
| 질문에 뭐라고 답할지 모르겠다 | "예시 보여 줘" 또는 "추천해 줘"라고 하면 후보를 줍니다 |
| 업무 OS에 넣은 내용이 사라졌다 | 브라우저 기록 · 쿠키를 지우면 사라져요. 백업 파일로 **복원** |
