# 업무 OS 화면 모듈 목록

통점에 맞는 것을 2~3개 추천한다. 첫 버전은 최대 3개.

| 모듈 | 무엇을 하나 | 이런 통점에 | 저장할 칸 (예) |
|---|---|---|---|
| **오늘 할 일** | 추가 · 체크 · 삭제, 마감일 순 정렬, 남은 개수 | (d) 까먹음, 할 일이 흩어짐 | 내용, 마감일, 완료 |
| **기록 표** | 한 건씩 추가 · 수정 · 검색 · 상태 필터 (작은 CRM/요청 관리) | (a) 찾기, 엑셀 여러 개 | PRD의 필드 표 그대로 |
| **상태 보드** | 할 일 / 진행 중 / 완료 칸으로 카드 옮기기 | 진행 상황이 안 보임 | 제목, 상태, 담당 |
| **자주 쓰는 문구** | 문구 모음, 버튼 한 번에 복사, 빈칸 `{이름}` 채우기 | (b) 같은 글 반복 작성 | 제목, 본문 |
| **루틴 체크** | 매일 · 매주 반복하는 체크리스트, 날짜가 바뀌면 초기화 | (d) 정기 업무 빠뜨림 | 항목, 주기, 마지막 완료일 |
| **숫자 요약** | 기록 표에서 이번 주 건수 · 상태별 개수 · 합계 자동 계산 | (c) 보고용 집계 | (기록 표에서 계산) |
| **주간 보기** | 이번 주 7일에 마감 · 일정 배치 | 일정이 머릿속에만 있음 | 날짜, 내용 |
| **링크 모음** | 자주 여는 사이트 · 문서 바로가기 | (a) 매번 찾아 들어감 | 이름, 주소, 묶음 |
| **보고서 초안** | 이번 주 기록을 모아 보고용 글로 만들어 복사 | (c) 주간 보고 작성 | (기록 표에서 생성) |

## 추천 조합 예시

| 통점 | 추천 |
|---|---|
| 할 일이 메모 · 메일 · 메신저에 흩어짐 | 오늘 할 일 + 링크 모음 + 루틴 체크 |
| 매주 엑셀을 합쳐 보고서를 만듦 | 기록 표 + 숫자 요약 + 보고서 초안 |
| 같은 안내를 하루에 여러 번 보냄 | 자주 쓰는 문구 + 기록 표 |
| 요청이 여기저기서 와서 진행 상황이 안 보임 | 기록 표 + 상태 보드 + 숫자 요약 |
