# [닉네임]의 업무 OS 제작 계획서

## 1. 만들 것
- 브라우저에서 여는 업무 OS `index.html` (기획: os-prd.md)

## 2. 파일 구조
```
my-os/
├─ os-prd.md
├─ os-build-plan.md
└─ index.html     ← 만들 파일 (CSS · JS 포함)
```

## 3. 데이터 저장 방식
| 저장 키 | 담는 것 |
|---|---|
| `myos:<모듈A>` | |
| `myos:<모듈B>` | |
| `myos:settings` | 예시 데이터 지웠는지 등 |

- 백업: 모든 `myos:` 키를 모아 `my-os-backup-YYYYMMDD.json`으로 내려받기
- 복원: 백업 파일을 골라 덮어쓰기 (덮어쓰기 전에 확인 창)

## 4. 만드는 순서
| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 뼈대: 머리말(날짜 · 인사) + 모듈 자리 + 백업 버튼 | 화면이 뜬다 |
| 2 | 저장 도우미 함수 (읽기 · 쓰기, try/catch) | 저장이 막혀도 화면은 뜬다 |
| 3 | 모듈 A | 추가 → 새로고침 → 남아 있음 |
| 4 | 모듈 B | 〃 |
| 5 | 모듈 C | 〃 |
| 6 | 예시 데이터 + 예시 지우기 | 처음 열면 예시가 보임 |
| 7 | 백업 · 복원 | 파일 받기 → 지우기 → 복원 |
| 8 | 휴대폰 대응 | 375px에서 한 줄 배치, 가로 스크롤 없음 |

## 5. 확인 방법
- `index.html`을 더블클릭으로 연다
- 완료 기준(os-prd.md 11번)을 하나씩 체크한다

## 6. 써 보고 고치기 예시
- "할 일에 마감일 색 표시를 넣어 줘 (오늘 마감은 빨강)"
- "기록 표에 '메모' 칸을 추가해 줘"
- "자주 쓰는 문구 모듈을 하나 더 붙여 줘"
