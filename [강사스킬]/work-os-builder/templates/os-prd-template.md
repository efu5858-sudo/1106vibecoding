## 1. 풀 문제
> "나는 [언제] [무슨 일]을 [얼마나 자주] 하는데, [어느 부분]이 가장 번거롭다."

| 항목 | 지금 | OS를 쓴 뒤 (목표) |
|---|---|---|
| 하는 방법 | (엑셀 / 메모 / 카톡 …) | 페이지 하나에서 |
| 걸리는 시간 | 주 __분 | 주 __분 |

## 2. 사용자 · 사용 장면
- 사용자: 나 혼자 (팀 공유는 범위 밖)
- 언제 여나: (예: 출근 직후, 퇴근 전 정리할 때)
- 어디서: PC 브라우저 / 휴대폰

## 10. 기술 조건 · 데이터 안전
- `index.html` 한 파일, 더블클릭으로 열림
- 저장: 브라우저 localStorage (이 PC, 이 브라우저에만 남음)
- 브라우저 기록을 지우면 사라질 수 있음 → 백업 버튼으로 JSON 저장
- 실제 고객 정보 · 회사 정보는 넣지 않는다

## 11. 완료 기준
- [ ] 항목을 추가하고 새로고침해도 남아 있다
- [ ] 백업 파일을 받고, 그 파일로 복원할 수 있다
- [ ] 휴대폰 폭(375px)에서 가로 스크롤이 없다
- [ ] 1번의 통점이 실제로 줄어든다 (일주일 써 보고 확인)
