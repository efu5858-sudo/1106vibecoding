무드 브라우저 — 설치 및 사용 안내

설치
1. 크롬 주소창에 chrome://extensions 입력
2. 개발자 모드 켜기 → '압축해제된 확장 프로그램을 로드합니다' 클릭
3. 바탕화면의 chrome-extension-2 폴더 선택
4. 퍼즐 아이콘에서 '무드 브라우저' 고정
5. 이미 열려 있던 웹페이지를 새로고침

날씨 / 클릭 효과
아이콘을 눌러 비·눈·벚꽃과 강도를 선택합니다.
강아지 또는 고양이 발바닥 효과를 선택하면 클릭할 때 표시됩니다.
날씨를 켜고 5초 동안 조작하지 않으면 아래에 눈·꽃잎이 쌓이거나 빗물이 고입니다.
화면 아래에서 마우스를 휘저으면 쌓인 효과가 흩날립니다. 5초간 쉬면 다시 쌓입니다.
눈·꽃잎은 최대 64px, 빗물은 최대 26px이며 클릭을 막지 않습니다.
날씨 변경·끄기·페이지 새로고침 시 쌓인 효과는 초기화됩니다.
일반 HTTP/HTTPS 웹페이지에서 작동하며 크롬 내부 페이지, 웹 스토어 등 제한된 페이지에서는 동작하지 않습니다.
웹페이지 접근 권한은 효과를 표시하기 위해 필요합니다. 페이지 내용은 수집하거나 전송하지 않습니다.
운영체제의 모션 줄이기가 켜져 있으면 움직이는 효과는 표시하지 않습니다.

알람 / 메모
미래 날짜·시간과 내용을 입력해 알람을 예약합니다.
크롬 실행 중에는 알림으로 표시되며, 종료 중 놓친 알람은 다음 크롬 실행 시 안내합니다.
크롬 및 Windows 알림 설정이 허용되어 있어야 합니다. 절전 등으로 알림이 지연될 수 있습니다.
메모, 효과 설정, 알람, 최고 점수는 이 브라우저에 저장됩니다. 확장 프로그램 제거 시 삭제됩니다.

비밀 커맨드
메모장에 /doom을 한 줄로 입력하면 즉시 실행됩니다. Enter는 필요 없습니다.
커맨드 줄만 지워지며 다른 메모 내용은 유지됩니다.
별도 탭에서 직접 제작한 레트로 슈팅 게임이 열립니다.
WASD 이동 / 좌우 방향키 회전 / Space 발사 / Esc 일시정지 / M 음소거
경비병은 3발, 드론은 2발로 처치할 수 있습니다.
적 8명을 모두 처치한 뒤 우측 아래 초록색 출구로 이동하세요.
초록 십자: 체력 회복 / 노란 상자: 탄약 보급
최고 점수는 승리하거나 사망했을 때 저장됩니다.
원작 게임의 이미지·음원은 포함하지 않습니다. 별도 서버나 빌드는 필요 없습니다.
