# 1라운드 제출 · 크롬 확장 프로그램 소개하기

설치해 보고 Codex로 처음 고친 「오늘 할 일 작성기」를 올리고, **어떤 기능을 하고 어떻게 생겼는지 소개**해 주세요.
올린 소개와 캡처는 강사 대시보드에 카드로 모여서 수업 중에 함께 봅니다.

## 내 폴더에 들어갈 것

```
round1/
└── 내닉네임/
    ├── manifest.json      ← 확장 프로그램 파일들 (그대로)
    ├── popup.html
    ├── popup.js
    ├── ...
    ├── README.md          ← 소개 글 (양식 복사해서 채우기)
    ├── screenshot.png     ← 대표 캡처 (꼭)
    ├── screenshot-2.png   ← 기능 쓰는 모습 (선택)
    └── screenshot-3.png   ← 하나 더 (선택)
```

## 순서

1. **양식 받기**: [`_양식/README.md`](_양식/README.md) 를 열고 오른쪽 위 다운로드 버튼으로 받아요. 내 확장 프로그램 폴더에 `README.md` 이름 그대로 넣습니다.
2. **소개 채우기**: 메모장이나 Codex로 열어서 칸을 채워요. `##` 으로 시작하는 제목 줄은 바꾸지 마세요. 대시보드가 이 제목으로 내용을 찾아요.
   - Codex에게 맡겨도 돼요: *"이 폴더의 확장 프로그램 코드를 읽고 README.md 양식을 채워 줘. 내가 바꾼 점은 ___야."*
3. **캡처하기**: 확장 프로그램 팝업을 열고 캡처해요. (윈도우 `Win + Shift + S`, 맥 `Cmd + Shift + 4`)
   - `screenshot.png`: 처음 열었을 때 모습 (꼭)
   - `screenshot-2.png`: 할 일을 넣거나 체크하는 등 기능을 쓰는 모습 (선택)
   - `screenshot-3.png`: 하나 더 보여 주고 싶은 장면 (선택)
   - 팝업 부분만 잘라서 찍으면 카드에서 잘 보여요.
4. **올리기**: 이 `round1` 폴더에서 **Add file → Upload files** → 내 닉네임 폴더를 **통째로** 끌어다 놓기 → **Commit changes**
5. **확인**: 올린 뒤 내 닉네임 폴더를 열면 소개 글과 캡처가 화면에 바로 보여요. 사진이 깨져 있으면 파일 이름을 확인하세요.

## 올리기 전에 한 번 더

- 캡처에 **메일 제목, 메신저, 다른 탭, 실명**이 찍히지 않았나요?
- 할 일 예시에 회사 업무 내용이 들어가 있다면 가짜 할 일로 바꿔서 찍어 주세요. 예) "물 마시기", "책 10쪽 읽기"
- 소개 글에 회사 이름, 연락처가 없나요?

## 막힐 때

| 증상 | 해결 |
|---|---|
| 소개 글에서 사진이 안 보인다 | 파일 이름이 `screenshot.png` 인지 확인 (대소문자, `.PNG` 아님, 띄어쓰기 없음) |
| 캡처가 `.jpg` 로 저장됐다 | `screenshot.jpg` 도 괜찮아요. 소개 글 안의 이름도 `.jpg` 로 바꿔 주세요 |
| 소개 글이 그냥 글자로만 보인다 | 파일 이름이 `README.md` 인지 확인 (`README.md.txt` 가 아닌지) |
| 대시보드에 내 기능이 안 나온다 | `## 주요 기능` 아래에 `- ` 로 시작하는 줄이 있는지 확인 |
