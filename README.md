# 1106 바이브코딩 실습 제출함

라운드가 끝날 때마다 내가 만든 크롬 확장 프로그램을 이 저장소에 올립니다.

| 폴더 | 언제 | 무엇을 |
|---|---|---|
| [round1](round1) | 1라운드 끝 | 설치해 보고 Codex로 처음 고친 할 일 작성기 |
| [round2](round2) | 2라운드 끝 | 기능을 더 붙이고 오류를 고친 버전 |
| [round3](round3) | 3라운드 끝 | 내가 원하는 기능으로 완성한 확장 프로그램 |

## 올리는 방법 (매 라운드 같아요)

1. **초대 수락** (처음 한 번만): 깃허브 가입 메일로 온 초대장에서 **Accept invitation** 누르기
2. **폴더 이름 바꾸기**: 내 확장 프로그램 폴더를 복사해서, 폴더 이름을 **내 깃허브 아이디**로 바꾸기
3. **스크린샷 넣기**: 확장 프로그램 화면을 캡처해서 그 폴더 안에 `screenshot.png`로 저장
4. **올리기**: 이 페이지에서 이번 라운드 폴더(예: `round1`) 클릭 → **Add file** → **Upload files** → 내 폴더를 통째로 끌어다 놓기
5. 아래 **Commit changes** 누르기

다 올리면 이렇게 보여야 합니다.

```
round1/
└── 내깃허브아이디/
    ├── manifest.json      ← 꼭 이 위치에 있어야 해요
    ├── popup.html
    ├── popup.js
    ├── ...
    └── screenshot.png
```

## 지켜 주세요

- **내 폴더만** 올리고 고칩니다. 다른 사람 폴더는 건드리지 않아요.
- 이 저장소는 누구나 볼 수 있습니다. **실명·연락처·회사 자료·비밀번호·키는 넣지 않습니다.**
- 같은 라운드에 다시 올리면 덮어써집니다. 마지막에 올린 것이 제출본이에요.

## 막힐 때

| 증상 | 해결 |
|---|---|
| Upload files 버튼이 없다 | 초대를 아직 수락하지 않았어요. 메일함 확인 |
| 파일이 `round1` 바로 아래에 흩어졌다 | 폴더 안 파일만 끌었어요. **폴더째** 끌어다 놓기 |
| Commit 할 때 오류 | 다른 사람과 동시에 올렸어요. 새로고침 후 다시 |
